# 자연어 → API 쿼리 변환 패턴

## 기본 패턴 10가지

### 1. 세율 질문
- 입력: "부가가치세율이 몇 퍼센트인가요?"
- 출력: `{ keyword: "부가가치세율", lawType: "NATIONAL" }`

### 2. 공제 요건 질문
- 입력: "소득세법 기본공제 요건이 어떻게 되나요?"
- 출력: `{ lawName: "소득세법", keyword: "기본공제", lawType: "NATIONAL" }`

### 3. 특정 조문 질문
- 입력: "소득세법 제26조 내용이 무엇인가요?"
- 출력: `{ lawName: "소득세법", articleNumber: "제26조", lawType: "NATIONAL" }`

### 4. 양도소득세 질문
- 입력: "아파트 양도 시 비과세 요건이 뭔가요?"
- 출력: `{ keyword: "양도소득세 비과세 요건", lawType: "NATIONAL" }`

### 5. 법인세 질문
- 입력: "법인세 손금산입 항목에는 어떤 것들이 있나요?"
- 출력: `{ lawName: "법인세법", keyword: "손금산입", lawType: "NATIONAL" }`

### 6. 지방세 질문
- 입력: "재산세 납부 기한이 언제인가요?"
- 출력: `{ keyword: "재산세 납부기한", lawType: "LOCAL" }`

### 7. 상속세 질문
- 입력: "상속세 기초공제 금액이 얼마인가요?"
- 출력: `{ lawName: "상속세 및 증여세법", keyword: "기초공제", lawType: "NATIONAL" }`

### 8. 예규·해석 질문
- 입력: "국세청 유권해석에서 이중거주자 과세 기준이 어떻게 되나요?"
- 출력: `{ keyword: "이중거주자 과세", lawType: "NATIONAL" }`
- 주의: 예규 검색 결과는 Trust Tier T3

### 9. 개정 전후 비교 질문 (시점 확인 필요)
- 입력: "예전에 양도소득세 세율이 어떻게 됐나요?"
- 처리: ❌ 즉시 변환하지 말 것 → "어느 시점을 기준으로 확인하시나요? (예: 2023.01.01)" 질문 필수
- 출력: 시점 확인 후 `{ keyword: "양도소득세율", lawType: "NATIONAL" }` + 시점 파라미터 추가

### 10. 복합 쿼리 (분리 처리)
- 입력: "법인세와 부가가치세를 동시에 알고 싶어요"
- 처리: 두 개의 별도 쿼리로 분리
- 출력:
  - `{ keyword: "법인세", lawType: "NATIONAL" }`
  - `{ keyword: "부가가치세", lawType: "NATIONAL" }`

## 시점 모호 패턴 (자동 차단 대상)

다음 표현이 포함된 쿼리는 변환 전에 시점 확인 요청 필수:
- `예전`, `이전 법`, `옛날`, `전에는`, `바뀌기 전`
- `개정 전`, `구 세법`, `예전 기준`, `과거에는`

**처리 방법**:
```
시점 모호 표현 감지 → "정확한 적용 시점(YYYY.MM.DD)을 알려주세요.
세법은 매년 개정되므로 시점이 다르면 적용 조문이 달라집니다."
```
