# 인용 포맷 통일 규칙 — citation-format SKILL

## 역할
모든 에이전트(tax-generator, law-verifier)가 법령 인용 시 동일한 형식을 사용하도록 한다.

## 핵심 규칙

### 1. 생략 표기
- ✅ `(…)` — 괄호 안 점 3개 (가운뎃점 아님)
- ❌ `...` — 불허
- ❌ `···` — 불허
- ❌ `[중략]` — 불허
- ❌ `(생략)` — 불허

### 2. 조문 번호 형식
- ✅ `제26조 제1항 제12호` — 원문 형식 그대로
- ❌ `제26조1항12호`
- ❌ `26조 1항 12호`
- ❌ `Art.26(1)(12)`

원문에 표기된 형식을 그대로 사용한다.

### 3. 원문 링크 첨부 (필수)
모든 인용에는 `source_url` 링크를 포함한다:
```
출처: [소득세법 제26조](https://law.go.kr/...)
```

### 4. 시점 라벨 (필수)
조문 번호 뒤에 반드시 시점 라벨을 부착한다:
- `소득세법 제26조 [현행]`
- `소득세법 제26조 [폐지: 2023.12.31]`
- `소득세법 제26조 [적용 시점: 2022.01.01 ~ 2023.12.31]`

### 5. Trust Tier 라벨 (필수)

| 라벨 | 이모지 | 의미 |
|---|---|---|
| 직접 근거 | 🟢 | T1/T2 출처, 직접 적용 |
| 유사 사례 | 🟡 | T3/T4 또는 논리적 유추 |
| 참고 자료 | ⚪ | 관련 쟁점 참고 |
| 폐지 | ⚫ | 폐지·삭제된 조문 |

### 6. 면책 고지 (필수 — 답변 하단)
```
[면책 고지] 이 답변은 공식 세법 API 검색 결과를 인용한 참고 자료입니다.
실제 세무 신고·의사결정은 반드시 담당 세무사·회계사의 검토를 받으시기 바랍니다.
```

## 완성 인용 예시

```
소득세법 제52조 제1항 [현행] 🟢
"거주자의 종합소득에 대한 종합소득세를 계산할 때 다음 각 호의 어느 하나에 해당하는
사람에 대해서는 해당 거주자의 해당 과세기간의 종합소득금액에서 다음 각 호에 따른
금액(이하 "기본공제"라 한다)을 공제한다. (…) 1. 해당 거주자: 150만원"
출처: [소득세법 제52조](https://www.law.go.kr/...)
```
