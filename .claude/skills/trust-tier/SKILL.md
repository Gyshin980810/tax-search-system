# Trust Tier 분류 로직 — trust-tier SKILL

## 역할
검색된 TaxLaw[] 배열의 각 항목에 올바른 Trust Tier(T1~T4)를 부여하고,
그에 따른 인용 라벨(🟢/🟡/⚪/⚫)을 결정한다.

## T1~T4 분류 기준

### T1: 법률·시행령·시행규칙 본문
**해당 문서 유형**:
- 소득세법, 법인세법, 부가가치세법 등 세법 본문
- 소득세법 시행령, 법인세법 시행규칙 등 하위 법령
- 지방세법, 지방세법 시행령

**라벨 활용**: 🟢 직접 근거 1순위

---

### T2: 법령 부칙·경과조치
**해당 문서 유형**:
- 법령 개정 시 부칙 조항 (`부칙 제1조 [시행일]`)
- 경과조치 규정 (`종전의 규정에 따른다`)

**라벨 활용**: 🟢 직접 근거 (특히 시점 분기 질문에서 필수)
> 개정 전후 시점이 다른 경우 T2 부칙·경과조치가 결정적 근거가 됨

---

### T3: 국세청 예규·해석례·기재부 회신
**해당 문서 유형**:
- 국세청 서면질의 회신
- 국세청 사전답변
- 기획재정부 세제실 유권해석

**라벨 활용**:
- T1/T2가 있으면 → 🟡 유사 사례
- T1/T2가 없고 사안이 일치하면 → 🟢 가능 (단, 사실관계 일치 여부 주석 필수)

---

### T4: 대법원·헌법재판소 판례
**해당 문서 유형**:
- 대법원 판결 (대판 XXXX.XX.XX. XXXX두XXXX)
- 헌법재판소 결정 (헌재결 XXXX.XX.XX. XXXX헌바XXXX)

**라벨 활용**: 🟡 유사 사례 또는 ⚪ 참고 자료

---

## 우선순위 규칙 (중요!)

```
T1 ≥ T2 > T3 > T4

IF (T1 또는 T2 존재):
  T3, T4 단독으로 🟢 인용 금지

IF (T1, T2 없음 + T3 사안 일치):
  T3 → 🟢 가능 (사실관계 일치 주석 필수)

IF (모두 없음):
  "직접 근거를 찾지 못했습니다" 명시 + 유사 사례 라벨로 제시
```

## 결정 플로우차트

```
검색 결과가 있는가?
  YES →
    T1/T2 조문이 있는가?
      YES → 🟢 직접 근거
      NO →
        T3 예규 있고 사안 일치?
          YES → 🟢 또는 🟡 (사실관계 비교 후 판단)
          NO →
            T4 판례 있는가?
              YES → 🟡 유사 사례 또는 ⚪ 참고
              NO → "직접 근거 없음" + 🟡 유사 사례 제시
  NO → "검색 결과 없음" 명시, 재검색 제안
```

## 폐지 처리

폐지된 조문(`expiry_date ≠ null`)은 항상 ⚫ 라벨 부착:
- `소득세법 구 제52조 [폐지: 2020.12.31] ⚫`
- 폐지된 조문을 현행인 것처럼 인용 금지
