# V2: 문자 단위 인용 무결성 확인 방법

## 목적
답변에 포함된 발췌 텍스트가 원문과 정확히 일치하는지 확인한다.
의역·요약·변형은 법적 의미를 왜곡할 수 있다.

## Grep 도구 활용 방법

### 1단계: 발췌문 추출
답변에서 인용 발췌문 위치:
- 큰따옴표(" ") 안의 텍스트
- 들여쓰기된 블록 텍스트
- "이에 의하면 ..." 뒤에 오는 원문 인용

### 2단계: Grep으로 원문 검색

```
Grep(
  pattern: <발췌문 전체 또는 핵심 구절>,
  path: TaxLaw.content,
  output_mode: "content"
)
```

- 결과가 있으면 V2 PASS
- 결과가 없으면 V2 FAIL

### 3단계: 생략 처리된 인용 검증
생략 표시 `(…)` 전후로 분리하여 각 부분을 별도로 Grep 검색:
1. 생략 전 텍스트 Grep → PASS
2. 생략 후 텍스트 Grep → PASS
3. 두 부분 모두 PASS여야 전체 V2 PASS

## 허용되는 생략 형식

| 형식 | 허용 여부 |
|---|---|
| `(…)` | ✅ 유일하게 허용 |
| `...` | ❌ 불허 |
| `···` | ❌ 불허 |
| `[중략]` | ❌ 불허 |
| `(생략)` | ❌ 불허 |

## 주의사항
- ❌ 퍼지 매칭 금지 (80% 유사도 등)
- ❌ 띄어쓰기 무시 금지
- ❌ 구두점 제거 후 비교 금지
- ✅ 원문과 100% 동일해야 PASS

## 흔한 V2 실패 패턴
- "공제한다" → "공제됩니다" (어미 변형)
- "이하 '기본공제'" → "이하 기본공제" (따옴표 누락)
- 띄어쓰기 변경 (원문은 붙여쓰기)
- 한자어 한글 변환 (令 → 영)
