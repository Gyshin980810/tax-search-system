> 상태: **🟡 회계사 검수 대기**

## 📌 이 문서의 사용법

1. 아래 각 케이스의 **제안 summary**를 법령과 대조하며 검토합니다.
2. `검수` 칸에 `✅확정` 또는 수정 내용을 적습니다.
3. 검수가 끝나면 저(AI)에게 "검수 끝났어, 머지해줘"라고 알려주세요.
4. 제가 확정된 summary로 `eval/golden_direct.json`에 18건을 머지하고, 신규 네거티브 2건을 추가합니다.
5. `npm run golden:status` → `npx vitest run tests/golden/run_golden.test.ts`로 30건 그린 확인.

> **왜 회계사 검수가 필수인가요?** (GOLDEN_SET_GUIDE §6.2, SSOT §13.2)
> 골든셋은 "AI 답변이 정확한지 채점하는 시험지"입니다. AI가 정답(summary)까지 만들면
> "출제자=채점자"가 되어 시험의 의미가 사라집니다. 그래서 AI는 **초안만** 만들고,
> 정답성은 반드시 회계사가 확정합니다. 특히 **세율 숫자·한도 금액**을 집중 확인해 주세요.
