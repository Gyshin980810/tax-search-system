# G-5: 지방세 재산세 납부 기한

## 질문
토지와 건물에 대한 재산세 납부 기한이 각각 언제인가요?

## 예상 조문

- 법령명: 지방세법
- 조문 번호: 제115조 (재산세 납기)
- Trust Tier: T1
- law_type: LOCAL
- 시점 라벨: [현행]

## 예상 라벨

- Trust Tier 라벨: 🟢 직접 근거
- 시점 라벨: [현행]
- 검증: V1~V6 모두 PASS

## 예상 답변 구조

1. 지방세법 제115조 [현행] 🟢 인용
2. 납기 구분 명시:
   - 토지: 매년 9월 16일 ~ 9월 30일
   - 건축물·주택(1/2): 매년 7월 16일 ~ 7월 31일
   - 주택(나머지 1/2): 매년 9월 16일 ~ 9월 30일
3. 지방세 검색임을 명시 (`lawType: "LOCAL"`)
4. 면책 고지 포함

## 지방세 특이사항

- `lawType: "LOCAL"` — 국세법령정보시스템이 아닌 지방세법령정보시스템 검색 결과
- 지방자치단체별 조례로 일부 달라질 수 있음 → 답변에 이 점 명시 필요

## 검증 기준

| 항목 | 기준 |
|---|---|
| V1 | 지방세법 제115조가 TaxLaw[]에 존재 (lawType: LOCAL) |
| V2 | 인용 발췌가 원문과 문자 단위 일치 |
| V3 | T1(지방세법 본문) → 🟢 라벨 적정 |
| V4 | [현행] 라벨 부착 |
| V5 | [면책 고지] 포함 |
| V6 | 🟢 라벨이므로 V6 적용 없음 |
