# TAX-035: PRD·SSOT 정합 — 심판례 관계 그래프(Impact Map) 명문화

> 작성일: 2026-05-25 / 선행 티켓: TAX-033 (코어 완료), TAX-034 (UI 완료)

---

## 목적

TAX-033/034에서 구현한 심판례 관계 그래프(Impact Map) 기능을 PRD·SSOT 문서에 명문화한다.
현재 PRD v2.2·SSOT v2.2에는 이 기능에 대한 FR·도메인 타입·마일스톤이 일절 없음.

## 배경

- TAX-033 완료: `/api/impact-map` API 코어 (심판례 → 관련법령·참조결정 그래프)
- TAX-034 완료: 심판례 카드 mermaid 토글 UI
- 코드 완성 후 문서 정합이 누락된 상태 (SSOT §10.4 DOD: 리포트 + 문서화 필수)

## 범위

### 변경 파일

| 파일 | 구분 | 내용 |
|---|---|---|
| `docs/PRD.md` | 수정 | FR-21/FR-22 신설, 도메인 엔티티 추가, 마일스톤 추가, 변경 이력 |
| `docs/SSOT.md` | 수정 | §2 디렉토리 책임 갱신, §11.2 차기 목록 추가, 변경 이력 |

### 명시적 제외

- 코드 변경 없음
- CLAUDE.md 수정 없음 (이미 §6.2 T3 심판례·§4 계층이 정합되어 있음)
