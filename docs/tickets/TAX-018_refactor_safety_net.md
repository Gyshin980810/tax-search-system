## 배경

골든셋(`golden_direct.json`)은 **검증기(lawVerifier)**만 커버한다.
**어댑터(nationalTaxLaw.ts)**의 변환 함수 4종이 만드는 TaxLaw 객체 전체를 기계적으로 고정하는 그물이 없어서, TAX-019~023 리팩터 시 "출력 무변경"을 자동으로 증명할 수 없다.

특히 4종 변환 함수의 `lawName` 생성 규칙이 서로 달라 빌더 통합 시 가장 깨지기 쉬우므로 **빈 기관명 케이스를 명시적으로 고정**한다.

| 자료 | lawName 규칙 | 기관명 빈 값일 때 |
|---|---|---|
| 판례 | `법원명 ? '{법원명} {사건번호}' : 사건번호` | 사건번호만 (폴백 없음) |
| 법제처 해석례 | `회신기관명 ? '{회신기관명} {안건번호}' : 안건번호` | 안건번호만 (폴백 없음) |
| 국세청 해석 | `'{issuingBody} {안건번호}'` (항상 결합) | `'국세청 {안건번호}'` (폴백 결합) |
| 심판례 | `재결청 ? '{재결청} {청구번호}' : 청구번호` | `'조세심판원 {청구번호}'` (폴백 결합) |
