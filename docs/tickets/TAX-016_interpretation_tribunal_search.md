## 1. Problem (문제 정의)

### 1.1 현재 동작 (TAX-015 완료 시점 가정)
- 검색 결과에 법령(T1·T2)과 판례(T4)는 포함되나, **국세청 해석례·예규(T3)**, **기획재정부 회신(T3)**, **조세심판원 결정례(T3)** 가 없음.

### 1.2 기대 동작
- 회계사 검색 시 위 3종이 검색 결과에 포함되고, 모두 T3로 분류되어 🟡유사사례/⚪참고자료로 제시된다.
- 각 자료는 고유 식별자(문서번호·결정번호)·생산기관(국세청/기재부/조세심판원)·회신일/결정일·원문 링크를 표기한다.
- 모든 인용이 law-verifier V1·V2를 통과해야 노출된다.

### 1.3 영향·중요도
- 실무 판단 순서(조문→해석례→심판례→판례)를 시스템이 온전히 보조하게 된다.
- 조세 불복 단계에서 조세심판원 결정례가 실제 판단 기준으로 자주 인용되므로 실무 가치가 큼.
