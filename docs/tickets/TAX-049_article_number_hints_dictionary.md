## 5. 매칭 정책 (참고)

- **부분 문자열 매칭**: 질문에 사전 키워드가 `String.includes()`로 포함되면 매칭
- **다중 매칭 허용**: 한 질문이 여러 항목과 매칭되면 모두 추가 (LLM rewrite 보조)
- **결과 prepend**: 기존 LLM rewrite 결과 앞에 `"[법령명] [조문번호]"` 형태 검색어 prepend → TAX-031 정확매칭 트리거
- **fallback**: 사전 미커버 질문은 기존 LLM rewrite로 자연 fallback (회귀 없음)
