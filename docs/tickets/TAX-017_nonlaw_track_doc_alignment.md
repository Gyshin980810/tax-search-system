## 1. Problem (문제 정의)

### 1.1 현재 상태 — 문서 위계 역전
- 문서 위계: `SSOT`(헌법) > `PRD`(사양서) > `CLAUDE.md`(행동 요약) > `ROADMAP`(로드맵).
- **하위인 ROADMAP(v1.5)은 비법령 트랙을 완전히 반영**(별도 트랙 섹션·요약표·심판례 T3 권고)했으나, **상위인 SSOT·PRD는 트랙 자체가 부재**.
- 이 상태에서 PRD를 사양 근거로 인용하면 실제 구현(127 테스트 그린·회계사 대면 동작)과 불일치.

### 1.2 기대 상태
- SSOT·PRD·CLAUDE.md가 실제 구현(판례 T4 / 법령해석례·국세청해석·조세심판원 결정례 T3 / `references` 트랙)과 정합.
- 특히 **조세심판원 결정례(심판례) = T3**가 헌법(SSOT)부터 명문화되어 위계 충돌 해소.

### 1.3 중요도
- SSOT/PRD는 향후 모든 작업의 사양 근거 → 부정합 방치 시 후속 티켓이 잘못된 사양을 인용할 위험.
