# Memory 법령 개정 대응 정책

> 작성일: 2026-05-12
> 목적: 매년 개정되는 세법에 대응하는 메모리 무효화 정책
> 관련: CLAUDE.md §6.2 (시점 라벨), TAX-008

---

## 1. 배경

한국 세법은 매년 다수 개정됩니다.

- 소득세법·법인세법: 매년 1/1 개정 다수 시행
- 상속·증여세법: 수시 개정
- 지방세법: 연 1~2회 개정

메모리에 저장된 조문 캐시가 최신 법령과 불일치할 경우 환각 답변 위험이 있습니다.
이 문서는 캐시 무효화 정책을 정의합니다.

---

## 2. 메모리 3계층 분리

| 계층 | 내용 | 갱신 주기 | 무효화 방식 |
|---|---|---|---|
| **user-global** | 회계사 선호 (응답 톤, 자주 쓰는 양식) | 영속 | 수동 갱신만 |
| **project-shared** | 시스템 운영 정보, 아키텍처 결정, 피드백 | 반영속 | 프로젝트 변경 시 수동 |
| **법령 캐시** | 조문별 원문·시점 정보 | TTL = 시행기간 (공포일~폐지일) | 무효화 트리거 자동 처리 |

> **법령 캐시만** 자동 무효화 대상.
> user-global과 project-shared는 수동 관리.

---

## 3. 무효화 트리거 3종

| 트리거 | 대상 | 처리 | 실행 명령 |
|---|---|---|---|
| **T1: 세법 개정 공포일** | 해당 조문 캐시 | 즉시 만료 표시 | `--trigger=개정공포일 --law-id=<조문ID>` |
| **T2: `[현행]`→`[폐지]` 라벨 변경** | 해당 조문 메모리 | 즉시 만료 표시 | `--trigger=폐지라벨 --law-id=<조문ID>` |
| **T3: 1월 1일 (회계 연도 전환)** | 전체 시점 라벨 | 재검증 알림 목록 출력 | `--trigger=연도전환` |

---

## 4. 무효화 CLI 사용법

```bash
# T1: 법인세법 제19조 개정 공포일 처리
node scripts/invalidate-memory.js --trigger=개정공포일 --law-id=법인세법_제19조

# T2: 소득세법 제89조 폐지 처리
node scripts/invalidate-memory.js --trigger=폐지라벨 --law-id=소득세법_제89조

# T3: 매년 1월 1일 실행 (전체 재검증 알림)
node scripts/invalidate-memory.js --trigger=연도전환

# 도움말
node scripts/invalidate-memory.js --help
```

**출력**: JSON `{ trigger, law_id, affected_laws: [], timestamp }`

## 5. 연간 유지보수 체크리스트

| 시점 | 작업 |
|---|---|
| 매년 1/1 | `--trigger=연도전환` 실행 → 출력된 파일 목록 수동 검토 |
| 법령 개정 공포 시 | 개정 조문에 T1 또는 T2 트리거 실행 |
| 분기별 | 만료 표시된 캐시 파일 정리 |
