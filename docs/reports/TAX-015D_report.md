# TAX-015D 구현 리포트 — 참고 목록 확장(인용 안 된 비법령 노출 + 개수 상향)

- **티켓:** `docs/tickets/TAX-015D_reference_uncited_expansion.md`
- **작업일:** 2026-05-21
- **상태:** 구현 완료 (회계사 수동 검증 대기)
- **선행:** TAX-015B/015C/016A (완료)

---

## 배경

회계사 테스트 중 "법령해석례가 참고자료에 안 보인다" 제기. 진단 결과:
1. 법령해석례(TAX-016A)는 본문이 있어 `citable`로 가서 인용 목록 후보가 되며, **참고 목록(본문 없는 자료 전용)에는 원래 안 들어가는 게 설계**였다.
2. 그런데 LLM이 해석례를 인용하지 않으면, 본문이 있어 참고 목록에도 못 가고 인용 카드에도 없어 **어디에도 안 보이는 사각지대**가 있었다.
3. 추가 진단: 회계사가 테스트한 주제(가지급금/법인세)는 **법령해석례 자체가 0건**이었음(법제처 해석은 양도세 등에 존재). 가지급금 등 국세청 자체 예규는 TAX-016B(별도 키) 영역.

본 티켓은 사각지대(2)를 해소한다: **검색됐지만 인용되지 않은 본문 있는 비법령(해석례·판례)을 참고 목록에 노출**하고, 상한을 5→10으로 올린다.

  - `identityKey()` 신규 — 인용 여부 비교용 식별자(법령=조문번호, 비법령=사건/안건번호).

  - `MAX_REFERENCES` **5 → 10**.
  - 답변 생성·검증 완료 후 `buildReferences`로 최종 참고 목록 구성해 반환.

**테스트 (수정/추가)**

  - "최대 5건" → "최대 10건"으로 갱신(12건 입력 → 10건 노출, 선고일 최신순 컷오프 확인).
  - 신규 2건: ① 인용 안 된 본문 있는 해석례가 참고 목록에 노출, ② 인용된 비법령은 참고 목록에 중복 노출 안 됨.

## 동작 규칙 (정리)

```
관련 참고자료(references) =
    본문 없는 비법령 자료(국세 출처 판례 등)
  + 검색됐지만 LLM이 인용하지 않은 본문 있는 비법령(해석례·판례)
  − 인용된 자료(식별자로 제외)
  → 검색어 관련도순(TAX-015C) 정렬 → 상위 10건
```

- 참고 목록은 **발췌(excerpt) 없이 제목·기관·일자·원문 링크만** 제공 → law-verifier V검증 대상 아님(citation 승격 금지, TAX-015B 원칙 유지).
- 인용된 자료는 인용 카드(발췌 있음)에, 인용 안 된 관련 자료는 참고 목록에 → **검색된 자료가 사라지지 않음**.

## 잠재 위험 / 한계

- **데이터 부재 주제:** 가지급금 등 법령해석례가 0건인 주제는 본 변경으로도 해석례가 안 보임(데이터 자체 부재). 해당 영역 국세청 예규는 **TAX-016B(data.go.kr 별도 키)** 필요.
- **참고 목록 길이:** 상한 10으로 화면이 길어질 수 있음(회계사 결정). 추후 접기/펼치기 UI 검토 가능.
- **본문 있는 참고자료:** 인용 안 된 해석례는 본문이 있지만 참고 목록에선 발췌를 제공하지 않음(의도 — V2 우회 금지). 회계사는 원문 링크로 확인.
