## 1. 근본 원인

운영 로그 19건은 전부 `verify_status = PASS`, `failed_checks = []`였다. 그러나 PASS는
"인용한 것의 정확성"만 검증하며 "더 나은 근거를 놓쳤는지"는 검증 범위 밖이다. 19건을
직접 대조한 결과, 사실상 같은 세법 쟁점을 물은 두 질문이 다른 결과를 냈다.

- "기업업무추진비 상품권 손비 인정 기준은?" → **법령**(법인세법 제25조) 매칭 성공.
- "접대비 손금 인정 기준 알려줘. 상품권의 경우로" → 법령 없이 **심판례만**.

원인: `articleNumberHints.ts`의 법인세법 제25조 항목 키워드가
`'기업업무추진비'`·`'접대비 한도'`·`'접대비 손금불산입한도'`·`'기업업무추진비 한도'`
로, "접대비"가 "한도"류 없이 **단독으로만** 등장하면 힌트가 매칭되지 않았다.

---

## 2. 변경 사항

### 파일 변경 목록
- `src/domain/articleNumberHints.ts` (수정) — 법인세법 제25조 항목 keywords에
  `'접대비'` 단독 키워드 추가(기존 4개 키워드는 그대로 유지).
- `tests/unit/articleNumberHints.test.ts` (수정) — 신규 테스트 3건
  (운영 로그 실제 질문 재현, 단독 "접대비" 매칭, 기존 키워드 무회귀).

### 보존한 것
- `lookupArticleHints` 매칭 로직(부분 문자열·중복 제거) 무변경.
- `ARTICLE_NUMBER_HINTS` 항목 수 47개 그대로(신규 엔트리 아님, 기존 엔트리에 키워드만 추가).
- `LAW_ALIASES` 무변경(별개 사전, 이번 스코프 밖).

## 4. 잠재 위험·제한 (정직 고지)

- 운영 로그 표본이 19건으로 작다. 이번 티켓은 **근거가 명확한 1건만** 타깃 해결했고,
  #13("개별소비세 감면" — 판례만 노출, 개별소비세법 카테고리 자체가 사전에 없음) 등
  나머지 약한 신호는 로그가 더 쌓인 뒤 재검토 대상으로 남겼다(임의 확장 금지 원칙 준수).
- `'접대비'` 단독 키워드 추가로 인한 오매칭 가능성은 낮지만 0은 아니다(드물게 소득세법
  사업소득 필요경비 맥락에서도 "접대비"가 등장할 수 있음). 회계사가 이 트레이드오프를
  인지하고 승인했다.
- 골든셋 회귀는 범위가 좁아 필수로 요구하지 않았다(회계사 결정). 필요 시 추후 실행 가능.
