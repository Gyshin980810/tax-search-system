**주요 변경:**
- **두 그물 병행 수집**(회계사 결정, 2026-07-04):
  - **Pass A — 참조법령(JO) 필터**: `lawSearch.do?target=prec&JO=<세법명>`이 참조조문 기준으로
    판례를 정밀 필터링(법인세법 1,521건, 엉터리 법령명 0건). 사건종류가 민사·일반행정이어도
    세법을 참조하면 포착. JO 목록 = **국세 8법 + 지방세 3법 × (법률+시행령) = 22개 질의**
    (`TAX_LAW_JO_BASE`).
  - **Pass B — 사건명 세목 그물 + 사건종류='세무'**: `search=1`(사건명) + 세목 키워드
    (`TAX_ITEM_NAME_QUERIES`, JO 11법 대응·제외 세목 없음), 결과를 사건종류='세무'로 좁혀 유지.
    JO 사각지대인 **참조조문 공란 하급심 세무 판례**를 보완(아래 실측 근거).
- **사건번호 정규화 토큰 dedup**: 기존 적재분(precedent-kr)과 API의 본문이 달라
  content_hash가 무력하고 표기도 이원적("2025두36013" vs "대법원-2025-두-34754")이라,
  `normalizeCaseTokens`(하이픈·공백 제거 후 "연도+부호+번호" 추출)로 DB·원장과 대조.
  병합 사건("2013구합59576, 2014구합67529(병합)")은 토큰 하나만 일치해도 기지 판정
  (중복 적재 방지 우선).
- 본문은 법원 출처만 수집(국세법령정보시스템 출처는 본문 미제공 — 어댑터와 동일 판정),
  판시사항+판결요지 원문 그대로(§6.1). 첫 실행은 자동 백필 겸용.

**JO 사각지대 규명(실측, 2026-07-04):** JO 전체 재수집(`--all`) 8,772건과 DB 판례 9,978건 대조
→ JO가 **2,552건 미커버**. 원인: ① 제외 세목만 참조(관세·개소세·주세·증권거래세) ~344건(정상)
② **참조조문 공란 하급심 ~2,200건**(심급 분포 고법 1,604·지법 724·대법원 185 = 91%가 하급심).
표본 5건 전부 law.go.kr 참조조문 공란·사건종류='세무' 확인 → Pass B로 보완.

**잠재 위험:**
- 토큰 dedup은 보수적(하나만 일치해도 기지) — 병합 신건이 구건과 번호 일부를 공유하는
  극단 사례에서 놓칠 가능성(드묾). 반대급부로 중복 적재는 차단.
- JO 목록·세목 키워드에 없는 세법(관세법 등)만 참조하고 사건명에도 안 드러나는 판례는 미수집
  — 회계사 결정으로 제외, 필요 시 `TAX_LAW_JO_BASE`·`TAX_ITEM_NAME_QUERIES` 배열 확장.
- 사건명에 세목이 드러나지 않고 세무 라벨도 아닌 판례(예: "부당이득금")는 Pass B로도 미포착(드묾).
- 첫 실행(백필)은 신규 수천 건 예상 — 임베딩 전 건수·비용 확인 후 진행 권장.
