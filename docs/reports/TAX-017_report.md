## 배경 — 문서 위계 역전 해소

비법령 직접검색 트랙(TAX-015~016)이 코드·ROADMAP(v1.5)에는 반영됐으나, 상위 문서인 **SSOT(헌법)·PRD(사양서)에는 누락**되어 "하위 문서가 상위보다 최신"인 위계 역전 상태였다. 본 티켓은 **SSOT → PRD → CLAUDE.md 순**으로 정합을 끌어올려 역전을 해소했다.

> ⚠️ 순서가 중요: 심판례 T3를 SSOT보다 PRD에 먼저 쓰면 "PRD vs SSOT" 충돌로 SSOT 우선 적용되어 PRD가 무효화됨. 그래서 **헌법(SSOT) 우선**.

---

## 회계사 결정 사항 (반영됨)

| 결정 | 선택 |
|---|---|
| 반영 범위 | SSOT→PRD 정식 정합 |
| FR 처리 | **새 FR 신설**(FR-19 직접검색 / FR-20 참고목록) — FR-10 흡수 아님 |
| `MAX_REFERENCES` | "기본 10건, **회계사 조정 가능 파라미터**" 표기 |
| §9.3 라벨 모순 | "직접 매칭 라벨은 **Trust Tier를 따른다**"로 보정 |
| 비법령 골든셋(G-N1~N4) | PRD 편입 **보류** (정답값 검수 후) |

## 변경 사항 요약 (문서 3종, 코드 0)

### 1단계 — SSOT v2.1 → **v2.2** (`docs/SSOT.md`)
- **§7.6 Trust Tier 표** — T3에 법령해석례·**조세심판원 결정례(심판례)** 명문 추가 + 각주(회계사 결정 T3). ⭐차단 이슈 해소.
- **§7.2 필드 강제 표** — `sourceType`(법령/판례/해석례/심판례) + 비법령 식별자(`caseNumber`)·생산기관(`issuingBody`)·결정·선고·회신일(`decisionDate`) 행 추가.
- **§7.4 V1** — 통과 조건에 자료유형별 식별자 분기(법령=조문번호 / 비법령=`caseNumber`, 레거시=법령) 명시.
- **§7.4 (신규 규칙)** — 참고 목록(`references`)은 **V1~V6 비대상·citation 승격 금지** 명문화.
- **§3.3 RAG [2]단계** — 비법령 직접검색(판례·해석례·심판원 결정례) 포함 명시.
- 헤더·변경 이력 v2.2.

### 2단계 — PRD v2.1 → **v2.2** (`docs/PRD.md`)
- **§5.2** — **FR-19**(비법령 직접검색)·**FR-20**(참고 목록) 신설 + FR-10을 "의미 유사도용·직접검색 보완"으로 한정 + 보완 관계 주석.
- **§6.1 Trust Tier 표** — T3에 심판례 명문 + 각주(SSOT 정합).
- **§6.5.1 V1** — 식별자 자료유형별 분기 명시.
- **§6.5.3 (신규)** — 참고 목록 V검증 비대상·인용 승격 금지. 기존 "구현 위치"는 §6.5.4로 번호 조정.
- **§9.2.1** — [2]단계 비법령 직접검색·[3]단계 `references` 반영.
- **§9.3** — [1차] 비법령 직접검색 포함 + **"직접 매칭 라벨은 Trust Tier를 따른다"** 모순 보정 + 참고 목록 주석.
- **§10.1** — `TaxLaw`에 `sourceType`·비법령 필드, `LabeledAnswer`에 `references` 추가.
- **§10.2** — 필드 표에 `sourceType`·비법령 식별자 행 동기.
- **§16 마일스톤** — 별도 트랙(Off-roadmap) 행 추가 + M5 "선제 달성" 주석.
- 헤더·변경 이력 v2.2.

### 3단계 — CLAUDE.md (`CLAUDE.md`)
- **§6.2 Trust Tier 표** — T3에 심판례 명문 + 각주(SSOT·PRD 정합).
- **§6.4 V1** — 식별자 분기(법령=조문번호 / 비법령=`caseNumber`).
- **§6.4 (신규 한 줄)** — 참고 목록 V1~V6 비대상·인용 승격 금지.
- 헤더 갱신일 2026-05-22(PRD v2.2·SSOT v2.2 정합).
