# [TAX-6B-31] 인용 연결망(citation_edges) 구축·적재 리포트

> 작성: 2026-07-06 · 상태: **적재 완료** (DB 132,381행)

---

## 1. 요약

판례·심판례 원문에서 인용 관계를 추출해 `citation_edges` 테이블(순수 텍스트 엣지,
**임베딩 무관·과금 0**)로 Neon에 적재했다. 구축 중 엣지 품질 평가에서 **심판례
사건번호 0채움 표기 불일치**(body 엣지 연결률 5.8%)를 발견, `normalizeTribunalCaseNumber`
도입으로 **연결 +10,786건 회복 + 유령 중복 엣지 ~10,800건 제거** 후 적재했다.

## 3. 발견·수정한 결함: 심판례 사건번호 0채움 불일치

- **증상**: body 유래 심판례→심판례 엣지 in_corpus 5.8%
- **원인**: DB 표기 `조심2018지0166`(일련번호 4자리 0채움) vs 본문 표기 `조심 2018지166`
  — `normalizeCaseNumber`(공백 제거만)로는 다른 사건으로 취급
- **수정**: `src/domain/precedentCitation.ts`에 `normalizeTribunalCaseNumber` 추가
  (공백 제거 + 일련번호 4자리 `padStart`, 4자리 이상은 무변경).
  `extractCitedTribunalNumbers`·`extractTribunalSelfId`·코퍼스 로드·fromId 폴백에 일괄 적용
- **효과 실측**: body 매칭 834 → 11,620건(81.3%). 이 중 대부분이 field 엣지와 동일
  인용쌍으로 병합(정밀 원천 우선)되어 총 엣지 143,181 → 132,381로 감소(중복 제거는 개선)
