> 정식명으로 정규화해 동음이의 법령 오매칭("지방세법"→"지방교부세법")을 차단했다.

### 주요 변경
1. **약칭 사전(닫힌 집합 6개, 회계사 확정 2026-05-24)**: 조특법→조세특례제한법, 국기법→국세기본법,
   부가세법→부가가치세법, 상증세법/상증법→상속세 및 증여세법, 종부세법→종합부동산세법.
2. **정규화 후 검색**: `fetchArticles`가 `normalizeLawName(keyword)`로 정식명을 만들어 `searchLaws`에 전달.
3. **정확매칭 선택**: `selectBestLaw`로 `완전일치 > 접두일치 > 부분일치 > 폴백(laws[0])` 순 선택.
   매칭 근거는 로깅 대신 `matchType` 반환값으로 노출(어댑터에 로깅 인프라 없음 → §9.7 최소 변경).

### 아키텍처·원칙 정합
- 약칭·매칭은 Adapter 계층 정규화(약칭 사전은 도메인 상수) → §4 위반 없음.
- 검증[4]·law-verifier **무변경**(검색 품질 개선이지 검증 변경 아님).
- 원문 보존(§6.1) 무관(본문 가공 없음 — content 조립은 TAX-032 소관).
- 비법령 4트랙(판례·해석례·심판례) 검색은 **변경하지 않음**(범위 최소화). 약칭 정규화는 법령 트랙에만 적용.

## 잠재 위험
- **`content 짧음` 경고는 여전함**: 통증 B(조문 본문 누락)는 본 티켓 범위 밖 → **TAX-032**에서 해결 예정.
- **부분일치(includes) 과매칭 가능성**: 완전·접두일치가 먼저 잡으므로 실사용 위험 낮음. 골든셋 회귀가 안전망.
- **약칭 사전 확장**: 신규 약칭은 회계사 승인 후 추가(임의 추가 금지). 약칭이 둘 이상 법령을 가리키면 등록하지 않음(보수).
- **약칭 UI 노출 승격 시**: PRD FR 신설·SSOT 반영 별도 정합 티켓 필요(임의 FR 금지).
