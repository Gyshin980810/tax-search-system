### AI 종료점: 골격 생성 완료 ✅

### 회계사 작업 (AI 비대상)

각 케이스마다 아래 3가지를 작성 후 `golden_direct.json`에 머지하세요:

1. **summary** — 회계사의 실제 정답 답변 (`__TODO_회계사_작성__` 교체)
2. **excerpt** — content 전체가 기본값, 핵심 결정요지로 좁혀 작성
3. **temporalLabel** — 결정일 기반 `[결정: YYYY.MM.DD]` 또는 `[현행]` 확정

```json
// 작성 예시 (draft에서 수정)
"summary": "이 사건에서 조세심판원은 ...",
"excerpt": "청구인이 ... 취득하였으나, ... 인정이자율 선택 방식 ...",
"temporalLabel": "[결정: 2018.03.14]"
```

### 머지 후 측정

```bash
npm run golden:status   # 진행률 확인
npm run test            # G-2 포함 vitest 회귀
```

라벨 정확도 ≥ 95% 달성 여부를 status 및 회귀로 측정합니다.
