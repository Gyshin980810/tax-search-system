## 1. 30초 요약

TAX-029 P95 100회 측정에서 V3 라벨 부적절 9건(8.7%) 잔존의 근본 원인을 단건 진단으로 식별했다.

- **근본 원인**: SYSTEM_PROMPT가 "T3·T4에 🟢 금지" 규칙은 가지고 있었지만 **"T1·T2 자체가 검색 결과에 하나도 없는 경우"의 특수 가이드가 누락**되어 있었음. 그 빈틈으로 LLM이 가끔 "어쩔 수 없이 T3에 🟢라도 줘야지"하는 변동성 발생.
- **해결**: SYSTEM_PROMPT에 `[T1·T2 부재 시 동작 규칙]` 1블록 추가(~8줄). V3 판정 로직(`lawVerifier.checkV3`)·`TIER_ALLOWED_LABELS` 상수·골든셋 데이터 **전부 무변경** (CLAUDE.md §6.4 준수).
- **검증 결과**: 단건 진단 11회 V3 **PASS 11/11 (100%)**. G-S-소득-03 직전 1/3 → 5/5 개선. 회귀 표본 3건(G-1·G-S-법인-01·G-S-부가-01) 모두 PASS.

### 2.2 주요 변경 내역

추가된 SYSTEM_PROMPT 블록 (라벨 결정 절대금지 블록 직후):

```
[T1·T2 부재 시 동작 규칙 — TAX-048]
검색된 조문 목록 전체가 (T3) 또는 (T4)만 있고 (T1)·(T2)가 하나도 없는 경우:
- 어떤 출처에도 🟢직접근거 절대 부여 금지. "T3밖에 없으니 어쩔 수 없이 🟢"는 잘못된 판단입니다.
- 모든 citations 라벨은 🟡유사사례 또는 ⚪참고자료만 사용.
- summary 첫 문장에 "직접 근거(법령 본문)를 찾지 못했습니다." 를 반드시 명시.
- 단정형 표현 금지. "유사 사례에서는 …" / "참고가 될 수 있는 자료" 형태만 사용.
- 회계사가 T3 자료를 법령처럼 인용해 가산세 위험에 노출되지 않도록 보호하는 게 시스템 의무입니다.
```
