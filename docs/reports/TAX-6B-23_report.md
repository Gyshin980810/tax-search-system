## 해석

1. **내부 엣지(16,336) > 외부 엣지(10,001)** — 세무 판례가 코퍼스 밖(민사·일반)보다 **세무 판례끼리 더 많이 인용**한다. PoC 착수 전 핵심 가설("세무 판례는 외부만 인용할 수도 있다")이 **반증**됨.
2. **밀도 64.3%는 하한값** — 보수적 추출(병합사건 2번째 토큰 누락, `판결/결정` 맥락 밖 인용 누락)이므로 실제 연결은 같거나 더 촘촘.
3. **허브 구조 존재** — 30회 이상 피인용되는 핵심 판례가 다수. 그래프의 "관련 판례 더보기"·"핵심 선례 추적"에 직접 활용 가능.
4. **고립 노드 17%** — 일부는 그래프 탐색 대상이 아님(벡터 의미검색으로 보완). 그래프는 의미검색의 **대체가 아닌 병행**임을 재확인.

## 잠재 위험 / 한계

- **추출 누락(하한 편향)**: 병합사건 콤마 표기(`2001두4849, 2001두4856 판결`)의 2번째 사건번호, `판결/결정` 단어가 떨어진 인용은 미추출. → 밀도는 보수적 하한.
