```

------------------------------------------------------------
```

### 3.3 1차 → 2차 비교: 진짜 병목이 드러남

| 항목 | 1차 (10s 타임아웃) | 2차 (25s 타임아웃) | 의미 |
|---|---|---|---|
| 답변 생성 평균 | 8.84s | **11.74s** (자연 종료 기준) | 25초 한도에서 자연 분포 측정 가능 |
| 답변 생성 타임아웃 박힘 | 80건 | 19건 | 타임아웃 정합으로 대부분 자연 완료 |
| **답변 검증 실패** | 7건 | **66건** | **1차에서는 타임아웃에 가려져 보이지 않았던 진짜 병목** |
| 정상 응답 | 10/100 | 14/100 | 약간 개선되었으나 여전히 운영 부적합 |
| 누적 P95 | 21.12s | 32.05s | V1~V6 재시도(V1: 재검색+재생성)가 누적시간 증폭 |

### 3.4 핵심 발견: V1~V6 검증 통과율 14%

운영 골든셋 40건을 cyclic 100회 호출 시 **회계사에게 노출 가능한 답변은 14건(14%)뿐**.

```
[100회 호출]
  ↓
[1차 시도] answer 100건 생성
  ↓
[검증] V1~V6 통과율 매우 낮음
  ↓
[재시도] V1(재검색+재생성) 또는 V2~V6(재생성) — 약 79건
  ↓
[2차 검증] 여전히 대부분 실패
  ↓
[최종] 14건 PASS → 회계사 노출 / 66건 FAIL → "확인 어려움" 안내 / 18건 타임아웃 / 2건 네트워크
```

`answer 단계 n=179`는 100회 + V1 재시도 79회를 뜻하며, **V1 환각 검출이 폭발적으로 작동했음을 보여줍니다**. 시스템이 의도대로 환각을 차단 중이지만, 차단 후 회계사 노출 가능한 답변이 14%에 불과합니다.

### 3.5 운영 표면 통찰 (성공 14건의 응답시간 분포)

```
정렬: 4.08, 5.71, 6.30, 7.44, 8.33, 13.16, 13.93, 13.94, 14.24, 14.70, 15.80, 19.25, 26.77, 32.05 (초)
```

- 처음 8건은 **첫 시도 성공(8.33s 이하)** — RAG 5단계가 PRD §7.1 합격선 안에 들어옴
- 9~12번째는 **재시도 1회 후 성공(13~20s)**
- 13~14번째는 **재시도 2회 또는 V1+재생성 후 성공(26~32s)**

**즉, V1~V6 통과율만 개선되면 P95 합격선(< 15s) 달성 가능성이 높습니다.**

## 5. Phase 4 게이트 해제 판단

### ⚠️ **3차 판정: 조건부 보류 — Pass rate·V1~V6 합격, 누적 P95만 미달**

**판단 근거 (TAX-041 옵션 A 적용 후):**

1. ✅ **Pass rate 88%** — PRD §15.2 목표 70/100 큰 폭 상회 (12.5% → 88%, 7배)
2. ✅ **V1~V6 통과율 84.6%** — 운영 노출 가능 비율 충분 (V2 1.9%·V3 13.5%·V6 1%만 실패)
3. ✅ **V2 인용 무결성 0% citation 실패** — 옵션 A 어댑터 자동 추출 완벽 작동
4. ✅ **P50 12.19s** — 절반 이상 케이스가 합격선 안에 들어옴
5. ❌ **누적 P95 24.66s** (이상치 제외) — 15s 합격선 초과
6. ❌ **15s 이하 비율 70.1%** — 운영 표면 부족 (P95 기준 85%여야)

**미달 원인:**
- 답변 생성 25s 타임아웃 박힘 4.6% (4/87) — LLM 자체 응답이 25s 이상
- 20s~25s 구간 응답이 17% — TAX-040 타임아웃 한계 근처
- V3 라벨 부적절 14건 → 재시도 1회 추가로 누적 시간 증폭

**미달 의미:**
"본 측정 자체는 운영 표면을 반영하지 못함" 가능성 ↓ (옵션 A 적용 후 V1~V6 통과가 84.6%로 안정화).
**진짜 잔여 병목은 LLM 답변 생성 단계의 25s 박힘**. PRD §13 한도 30s 이내에서 LLM 응답 시간 단축이 필요.
