## 배경

TAX-052가 생성한 `scripts/laws_for_embed_nonlaw.json`(89건: 심판례 83·해석례 3·판례 3)을
기존 `embed.ts`(`--input`)로 Neon pgvector DB에 적재한다.
적재 후 `smokeVector.ts`에 비법령 전용 질의를 추가해 vector 단계 의미검색이 실제로 비법령을 발굴함을 입증한다.

## 변경 사항 요약

### 파일 변경 목록

| 파일 | 작업 | 비고 |
|---|---|---|
| `scripts/embed.ts` | ✏️ 수정 | `BATCH_SIZE` 100 → 20 (OpenAI 토큰 한도 버그 수정) |
| `scripts/smokeVector.ts` | ✏️ 수정 | 비법령 전용 질의 `NONLAW_QUERIES` 3건 추가 + [A-2]·[B-2] 검증 블록 추가 |

> ✅ `src/` (도메인·어댑터·usecase·검증 V1~V6) **무변경**.

### embed.ts BATCH_SIZE 수정 이유

비법령(심판례·해석례) 본문은 평균 수천 자로 법령 조문보다 훨씬 길다.
`BATCH_SIZE=100`이면 89건 × max 6,000자 ≈ 53만 토큰 → OpenAI 300,000 토큰/요청 한도 초과.
→ `BATCH_SIZE=20`으로 축소: 20건 × 6,000자 = 12만 토큰/배치로 안전.
기존 법령 38건(짧은 조문)에도 영향 없음 — 배치 수만 늘어남.
