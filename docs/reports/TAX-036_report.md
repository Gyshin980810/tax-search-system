### 3. sourceLaws 정책 결정 (2026-06-01)

회계사 결정으로 **현재 정책 유지** 채택. 토큰·API 호출 비교 후 비용 효율 우선.

| 항목 | 현재 정책 유지 | sourceLaws 확장 |
|---|---|---|
| 1건당 LLM 입력 토큰 | ~700 | ~3,700 (5.3배) |
| 어댑터 API 호출 | 1회 | 2~3회 |
| 월 LLM 비용 (1,000건 가정) | $0.11 | $0.55 |
| 캐시 적중률 | 높음 | 낮음 |

**적용 패턴**: summary 내 인용은 직접근거 1개 조문만 sourceLaws에 보존, 다른 조문은 참조형 문구로 표기 ("(제52조 제4항 대리납부에 따른 세액 포함)"). description에 `[AI초안·회계사검수필요·X조 참조]` 마커 부착하여 회계사가 참조 부분 정확성을 검수.

메모리 `feedback_golden_sourceLaws_policy.md`에 저장 — 향후 세션·다른 세목 진행 시 자동 적용.

### 4. V4 시점 라벨 임시 정책 (2026-06-01)

비법령은 시행일 개념이 없어 `buildNonlawCases.ts`가 `[결정: YYYY-MM-DD]` 형식 부착 → lawVerifier V4 정규식(`[현행]`·`[적용 시점]`·`[폐지]` 3종만 허용) 불일치로 V4 FAIL.
